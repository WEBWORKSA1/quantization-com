What 4-bit actually buys you

An 8-billion-parameter model stored at 16 bits needs about 16 GB just for its weights. The same model in the popular Q4_K_M format averages roughly 4.9 bits per weight, so it needs about 4.9 GB — small enough for a mid-range laptop GPU.

Questions people ask first

Short answers; each links to the full guide.

What is quantization, in one sentence?

It is representing values with fewer distinct levels — fewer bits — by rounding each value to the nearest allowed level, which saves memory and bandwidth at the cost of a small, measurable error. Read the full explanation.

Does quantizing an LLM make it worse?

Slightly, and how slightly depends on the bit width and method. 8-bit formats are usually close to the original; 4-bit formats lose a little more; below about 3 bits quality drops faster. Measure it on your own task rather than trusting a single benchmark. See the guide.

Which GGUF file should I download?

Q4_K_M is a common default when memory is tight, Q5_K_M or Q6_K if you have room, and Q8_0 if you want near-reference quality. Use the VRAM calculator to check what fits, then read GGUF quant types explained.

Is it the same "quantization" as in audio or physics?

The digital meaning — rounding to discrete levels — is shared by AI, ADCs, audio and MIDI timing. In physics, quantization describes nature itself: some quantities can only take discrete values. The intuition of steps is the same; the cause is different. Physics guide.
